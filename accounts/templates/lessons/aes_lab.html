AES Encryption (Advanced Encryption Standard)

Introduction

AES is a modern symmetric encryption algorithm.
It uses the same secret key for encryption and decryption.
The output ciphertext is encoded in Base64 format.

AES-128 / AES-192 / AES-256 supported.
This implementation uses AES-256 internally.

AES Round Overview

AES works on 128-bit blocks arranged as a 4x4 byte matrix.
Each round performs structured transformations to ensure confusion and diffusion.

Round Steps

  • SubBytes: Non-linear substitution using S-Box.
    During SubBytes, each bytes of states is transformed by looking up table S-box using their value as address.
  • ShiftRows: Row shifting for diffusion.
    During ShiftRows, last 3 rows of states are cyclically shifted over different number of bytes based on row number.

  • MixColumns: Mathematical column mixing.
    During MixColumns, perform operation on each column of states. Basically it use matrix multiplication to transform each column of states. Transform matrix is fixed and calculation treats each bytes as polynomials with coefficients in GF(2^8), modulo x^4 + 1.
  • AddRoundKey: XOR with round key.
