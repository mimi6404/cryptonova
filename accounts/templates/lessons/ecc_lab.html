Elliptic Curve Cryptography (ECC)

Introduction

ECC is an asymmetric cryptographic algorithm.
It provides strong security with smaller key sizes compared to RSA.

Based on Elliptic Curve Discrete Logarithm Problem (ECDLP).

Practice Lab

ECC Concepts

1. Choose an elliptic curve.

2. Generate private key (random number).

3. Public key = private key × generator point.

Signing: Uses private key.

Verification: Uses public key.

ECC offers high security with smaller keys compared to RSA.
