Vigenère Cipher

Introduction

Vigenère cipher is a polyalphabetic substitution cipher.
It uses a keyword where each letter represents a shift value.
The keyword repeats to match the plaintext length.

Example:
Plaintext = HELLO
Keyword = KEY
Ciphertext = RIJVS
